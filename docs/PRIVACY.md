# Privacy statement

## Application behavior

This release has no account system, form for personal details, public user content, analytics SDK, advertising SDK, external AI API, or remote database. Game answers and current typing input are used in the browser for interaction. Typing Sprint does not store the entered sentence.

If browser local storage is available, the app stores only a versioned object containing completed game IDs and personal-best numeric scores. It is not transmitted by application code. Users can reset progress from the Arcade or clear site storage in their browser. If storage is blocked or malformed, activities remain usable and the app reports that progress could not be read or saved.

## Hosting and legal review

This is a description of the application bundle, not a claim that a future hosting provider collects no information. Static hosts can process request metadata and operational logs under their own terms. No deployment has been configured or verified. Before public launch, choose a host, review its current privacy terms, add any necessary notice, and assess applicable child privacy, consumer protection, and accessibility requirements for the intended jurisdictions and age group.

No public contact address has been configured; do not publish a placeholder as if it were monitored.
