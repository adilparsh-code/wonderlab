# Product specification

## Audience and purpose

WonderLab is an English-language learning arcade for students aged 11–16, including Indian learners and an international audience. It makes maths, logic, science, and beginner programming ideas explorable through short browser activities.

## Principles

- Free core access, without accounts or payments.
- Mobile-first interaction and keyboard-accessible controls.
- Original, accurate explanations with honest simplification notes.
- No third-party tracking, advertising, user-generated public content, or arbitrary code execution.
- Local-only optional game progress; core play must still work when storage is blocked.

## MVP acceptance

- Home, Arcade, How Things Work, Coding Lab, Challenges, About, Privacy, and Accessibility pages.
- Eight playable, replayable games with feedback and age/difficulty information.
- Six interactive science models, each with a knowledge check and limitations.
- Coding prompts for binary, conditions, and loops, evaluated with local fixed answers.
- Static export, focused logic/content tests, linting, type checking, and production build.

## Out of scope

Accounts, public leaderboards, social features, remote databases, payments, advertisements, analytics, external AI APIs, and general-purpose code execution.

## Release caveats

The local product does not establish hosting privacy terms, legal compliance in every audience jurisdiction, domain ownership, public contact details, independent accessibility certification, or an operational support process. These require review before public launch.
